DuckChain Core Protocol Documentation

DuckChain is a high-throughput, EVM-compatible Layer-2 rollup architecture purpose-built for high-frequency consumer applications and Telegram mini-app execution.

Overview & Architecture

DuckChain separates transaction sequencing from execution verification using a pipelined BFT consensus engine. Transactions submitted by consumer applications achieve soft sub-second finality on the sequencer cluster with periodic cryptographic state commitments submitted to layer-1 settlement anchors.

Quickstart JSON-RPC Query

Querying the latest block header using standard Web3 JSON-RPC over HTTPS:

curl -X POST https://rpc.duckchain.io   -H "Content-Type: application/json"   -d '{"jsonrpc":"2.0","method":"eth_blockNumber","params":[],"id":1}'

Sample standard response:

{
  "jsonrpc": "2.0",
  "id": 1,
  "result": "0xe3c8a8"
}
